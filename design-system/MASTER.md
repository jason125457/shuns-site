# shuns.site 設計系統 — A「底片暗房」

> 2026-10-25 由 ui-ux-pro-max 查詢結果（Vintage Analog / Retro Film 風格、Editorial 字體配對）整理，使用者選定。
> 所有頁面以本檔為準；個別頁面若有例外，寫在 `pages/<頁名>.md`。

## 氣質

暖、安靜、有手感。像一盒沖洗好的底片：照片與影片是主角，介面退到背景。
**克制是重點**：顆粒與歪斜只用在少數地方，不做漏光動畫、VHS 抖動、整頁復古濾鏡。

## 色彩（語意 token）

| Token        | 淺色             | 深色           | 用途                   |
| ------------ | ---------------- | -------------- | ---------------------- |
| `--bg`       | `#F3EBDD` 奶油紙 | `#1A1714` 暗房 | 頁面底色               |
| `--surface`  | `#FBF6EE`        | `#24201C`      | 卡片                   |
| `--fg`       | `#2A241D` 墨     | `#EDE3D2`      | 主要文字               |
| `--fg-muted` | `#5B4F42`        | `#B8AA96`      | 次要文字（皆 ≥ 4.5:1） |
| `--accent`   | `#9C4421` 鏽紅   | `#E08A5E`      | 連結、重點、播放鍵     |
| `--accent-2` | `#3F6E6F` 褪色青 | `#7FB0AE`      | 標籤、次要強調         |
| `--border`   | `#D9CBB3`        | `#3A332C`      | 分隔線、相框邊         |
| `--frame`    | `#FFFFFF`        | `#2E2924`      | 拍立得相框             |

- 鏽紅原始色 `#B4532A` 在奶油底只有約 4.2:1，小字不夠，所以文字用加深的 `#9C4421`。
- 深色模式不是反轉，而是「暗房」：暖黑底、紙色文字、提亮的鏽紅。跟隨系統設定，並提供手動切換。

## 字體

| 角色     | 字體                               | 備註                                                                |
| -------- | ---------------------------------- | ------------------------------------------------------------------- |
| 英文標題 | Fraunces（opsz 可變字重 400／500） | 有個性的襯線字                                                      |
| 中文標題 | Noto Serif TC 500                  | 只載入標題用的字重                                                  |
| 內文     | Noto Sans TC 400 ／ 系統無襯線字   | 內文 16px、行高 1.7                                                 |
| 中繼資料 | IBM Plex Mono 400                  | 日期、原唱、技術標籤，像底片邊上印的編號，例如 `2026.10 ▸ COVER 07` |

- 字級：12 / 14 / 16 / 20 / 28 / 40（手機上首頁大標降到 32）。
- `font-display: swap`；中文字體用 Google Fonts 分片載入，不要自己打包整套字型。

## 版面

- 手機優先，斷點 640 / 1024；內容最大寬 1100px，內文最大寬 68ch。
- 間距用 8 的倍數：區塊之間 96px（手機 64px），卡片內距 24px。
- 導覽列：`Shun` 標誌 ＋ 翻唱 ／ 專案 ／ 攝影 ／ 關於（頁內錨點），固定在頂部，捲動後加一條細底線。

## 元件

- **拍立得相框**（攝影、專案截圖）：`--frame` 白邊，上左右 8px、下 28px，邊框 `--border`。只在格狀列表裡給 ±1.5° 的輕微旋轉；滑過時轉正。`prefers-reduced-motion` 時不旋轉。
- **翻唱卡**：YouTube 預覽圖（點了才載入播放器，避免一次載入一堆 iframe）＋曲名（襯線字）＋ mono 一行「原唱 ▸ 日期」＋一兩句心得。
- **專案卡**：拍立得截圖 ＋ 名稱 ＋ 一段介紹 ＋ 技術標籤（mono、`--accent-2` 細框）＋ 按鈕「開啟網站 ↗」，公開 repo 才加「GitHub ↗」。
- **IG 嵌入**：使用官方 embed，外面套一層和拍立得同色的框，讓 IG 的白底看起來像相框；最後放「更多作品在 Instagram ↗」。

## 質感與動態

- 顆粒：整頁一層 SVG noise，透明度 0.06（深色 0.08），`pointer-events: none`，不放在文字底下加深。
- 動態只做三件事：區塊進場淡入加上移 12px（300ms）、相框滑過時轉正（200ms）、連結底線。都要尊重 `prefers-reduced-motion`。
- 不用：漸層按鈕、陰影堆疊、視差、自動輪播。

## 圖示

Phosphor（outline、1.5px 線寬），不用 emoji 當圖示。

## 檢查清單

- [ ] 淺色、深色兩種模式的文字對比都 ≥ 4.5:1
- [ ] 鍵盤操作時看得到 focus 框，跳到主內容的 skip link
- [ ] 圖片標好寬高或 aspect-ratio（CLS < 0.1），首屏以外的圖片 lazy load
- [ ] 375px 寬沒有橫向捲動
- [ ] YouTube／IG 嵌入點了才載入
